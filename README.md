# Stellar Scavenger: Core & Relics

Космический 2D-кликер на **Rust + Macroquad**: дроби планеты, добывай руду,
собирай флот автономных дронов-буров, сражайся с планетарными щитами боссов,
открывай 8 биомов галактики и раскапывай редкие космические реликвии.
Расти до престижа, сжигай галактику ради Тёмной Материи — и начинай снова,
сильнее, чем вчера.

```
ЛКМ по планете  ->  урон  ->  руда  ->  дроны  ->  биомы  ->  реликвии  ->  престиж
```

---

## Возможности

### Графика и UI
- Полностью **процедурная графика**: планеты генерируются на GPU-текстуру
  из 3D value-noise (бесшовная equirectangular-развёртка), с диффузным
  освещением, лимбовым затемнением, зеркальными бликами океанов,
  эмиссивной лавой/кристаллами, атмосферным ободком и кольцами.
- **Ноль эмодзи** — все иконки UI рисуются векторными примитивами
  (модуль `ui/icons.rs`: 29 иконок линиями, полигонами и дугами).
- Шрифт **Inter 4.1** (Regular + Bold, TTF, OFL) вкомпилирован в бинарь
  через `include_bytes!` — полная поддержка кириллицы, бинарь самодостаточен.
- Плавные анимации: всплывающий урон (floating text с упругим появлением),
  «потряхивание» планеты (пружина + screen shake), прогресс-бары HP с
  «призрачным» хвостом урона, анимированные панели, тосты, баннеры биомов.
- Системы частиц: искры, штрихи, ударные волны, конусы из точки удара,
  взрывы планет, лучи дронов.

### Сохранения и настройки
- `saves/save.json` — прогресс (руда, ТМ, планета, дроны, реликвии, престиж,
  статистика), `saves/settings.json` — настройки, `saves/*.bak` — бэкапы.
- **Атомарная запись** (tmp + rename), автосохранение **каждые 10 секунд**,
  при выходе (Esc) и после ключевых событий.
- Отказоустойчивая загрузка: основной файл -> бэкап -> дефолты.
- Настройки: громкость (общая/музыка/эффекты), разрешение, полный экран,
  скорость анимаций, показ FPS, тумблер и частота автокликера, mute.
  Применяются сразу и переживают перезапуск.

### Геймплей
- 8 биомов по 10 планет + босс с щитом на каждой 10-й; после 8-го биома —
  **бесконечные галактики** (x20 HP / x8 руда за галактику).
- 6 типов дронов-автокликеров с покупкой x1 / x10 / MAX.
- 3 апгрейда клика, криты, боссы с регенерирующими щитами
  (дроны против щитов эффективны лишь на 25% — бей руками!).
- **16 реликвий** четырёх редкостей с пассивными бонусами; дубликаты
  повышают уровень эффекта.
- **Престиж**: руда забега конвертируется в Тёмную Материю, которая тратится
  на 5 постоянных апгрейдов Звёздного Ядра.
- **Встроенный автокликер** — отдельный тумблер в нижней панели и в настройках.

### Админ-панель (F12 или ~)
Выдача руды/ТМ, мгновенное уничтожение планеты, слом щита, телепорт на любой
биом, пропуск планет, спавн любых реликвий (Shift — стопкой), режим Бога,
бесконечный урон, **регулировка time scale 0..5x**. Состояние админки
намеренно не сохраняется.

### Аудио
Все звуки и эмбиент-музыка **синтезируются кодом при запуске** (PCM16 WAV
в памяти): удары, криты, покупки, реликвии, взрывы, престиж + 16-секундный
зацикленный эмбиент-луп. Никаких аудиофайлов в репозитории.

## Сборка

Требуется Rust 1.75+ (лучше последний stable): <https://rustup.rs>

```bash
git clone https://github.com/your-name/stellar-scavenger
cd stellar-scavenger
cargo run --release        # запуск
cargo build --release      # бинарь: target/release/stellar-scavenger
```

### Системные зависимости

| ОС | Пакеты |
|---|---|
| Ubuntu/Debian | `sudo apt install libx11-dev libxi-dev libgl1-mesa-dev libasound2-dev pkg-config` |
| Fedora | `sudo dnf install libX11-devel libXi-devel mesa-libGL-devel alsa-lib-devel` |
| Arch | `sudo pacman -S libx11 libxi mesa alsa-lib pkgconf` |
| Windows | ничего (MSVC Build Tools через rustup) |
| macOS | ничего (Xcode CLT через rustup) |

`libasound2-dev` нужна только на Linux (аудиобэкенд ALSA). Без сети/звука
в системе игра всё равно запустится — аудиопоток деградирует без паники.

### Переменные окружения (dev)
- `STELLAR_NO_AUDIO=1` — отключить аудио (контейнеры, CI).
- `STELLAR_SMOKE_FRAMES=250` — автотест: игра сама покликает, купит дронов,
  уничтожит планету, сохранится и завершится кодом 0 с `SMOKE OK`.

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ | Удар по планете |
| F12 или ~ | Админ-панель |
| F11 | Полноэкранный режим |
| M | Mute |
| Ctrl+S | Сохранить сейчас |
| Esc | Закрыть окно/панель; повторно — выход с сохранением |

## Архитектура

```
src/
├── main.rs                  # Точка входа: Conf, игровой цикл, хоткеи
├── game.rs                  # Оркестратор: update/draw/process_actions
├── util.rs                  # Формат чисел, пружины, плавные бары, Rect
├── components/              # Данные сущностей
│   ├── planet.rs            #   8 биомов, кривые HP/наград, имена планет
│   ├── drones.rs            #   6 типов дронов, кривые стоимости/DPS
│   ├── relics.rs            #   16 реликвий, редкости, ролл дропа
│   └── particles.rs         #   Частицы и floating text (данные)
├── systems/                 # Поведение
│   ├── combat.rs            #   Урон, криты, щиты боссов, уничтожение
│   ├── economy.rs           #   Покупки x1/x10/MAX, престиж
│   ├── planet_render.rs     #   Процедурный псевдо-3D рендер планет
│   ├── particles_system.rs  #   Обновление/отрисовка частиц и текста
│   └── audio_system.rs      #   Синтез WAV: SFX + музыка
├── resources/               # Глобальное состояние
│   ├── game_state.rs        #   Валюты, прогресс, бонусы, Ядро, статистика
│   ├── settings.rs          #   Настройки + предзагрузка для окна
│   └── assets.rs            #   Шрифты (include_bytes!) + банк звуков
├── save_system/             # JSON-персистентность, атомарность, бэкапы
├── ui/                      # Весь интерфейс
│   ├── theme.rs, icons.rs, widgets.rs   # Палитра, векторные иконки, IMGUI
│   ├── background.rs        #   Звёзды/туманности/виньетка
│   ├── hud.rs               #   Верхняя и нижняя панели
│   ├── click_area.rs        #   Сцена планеты, HP/щит, орбиты дронов
│   ├── shop.rs              #   Ангар дронов + апгрейды
│   ├── relics_ui.rs         #   Реликварий (сетка 4x4)
│   ├── settings_ui.rs       #   Настройки
│   └── prestige_ui.rs       #   Престиж + Звёздное Ядро
└── admin_panel/             # F12-панель разработчика
```

Каждый кадр: `update()` (логика, time scale) -> `draw()` (немедленный UI,
ввод) -> `process_actions()` (мутации из UI-слоёв).
